# 神临战队GODARRIVAL Mark1 ver2.0.3开发日志
## 5.底盘运动——单一与多项

**描述**
如上所述，考虑到场地上环境的多样性，包括过桥，平坦地形的冲刺以及摘取方块时的细微调整，因此我们决定开发两种不同的运动模式，包括四向移动与全向可调速移动。】
**实现**
我们采用了SPI通讯协议来支持手柄接收器与STM32板之间的信号传输，并使用DWT模式来为代码运行提供恰当的计数延时，实现信息传输的高效性。而对于全向移动，则比四向移动多采用了一个晶振时钟输出PWM信号来支持摇杆信号的精准识别。

**困难与解决**（2）

在SPI通信协议中，延时往往决定了一辆小车最终呈现性能的关键，恰当的延时可以保障信息传输指令下达的高效，而不当的延时则会导致小车的反应迟钝甚至致使信号冲突，控制失灵。
我们在SPI通讯协议的构建中，一度以为不当的延时设置是导致PS2无法正常连接的重点问题。（当然，根本问题上面已经指出）所以做出了许多尝试，下面是我们第一版时所采用的延时代码设置：

void AX_Delayus(uint32_t us) {
uint32_t i ;
i = us * 1000;
while(i--);
}
在这个代码的基础上，我们先后烧录了i = us * 40,i = us * 200,i = us * 500,i = us * 1000,i = us * 2000,但均以小车无法接收信号而告终。
然后我们将这个问题喂给了Deepseek，以寻求一个刚刚合适我们代码的值。然而Deepseek却给我们提供了另一个方案---DWT。
在查阅了知乎上DWT的相关文章介绍后，我们决定使用DWT工具来重新设计小车内部的延时函数。（代码如下）

  void AX_Delay_Init(void)
  {
  CoreDebug->DEMCR |= CoreDebug_DEMCR_TRCENA_Msk;   //使能DWT外设,置DEMCR寄存器的TRCENA位为1
  DWT->CYCCNT = 0;   //清空CYCCNT
  DWT->CTRL |= DWT_CTRL_CYCCNTENA_Msk;   //写DWTCR寄存器的CYCCNTTENA位为1,启动CYCCNT计数
  }

  void AX_Delayus(uint32_t us)
  {
  uint32_t start = DWT->CYCCNT;
  uint32_t ticks = us * (SystemCoreClock / 1000000U);   /* 72MHz → 72 */
  while ((DWT->CYCCNT - start) < ticks) { }             /* 无符号回绕，天然防溢出 */
  }

  （相关贴址：STM32笔记04-DWT实现精准定时和时间测量 - Bad-Boy17的文章 - 知乎 https://zhuanlan.zhihu.com/p/675301162 ）
这样，我们算是排除了延时设置可能造成的PS2连接不上问题。

**困难与解决**（3）

小车成功接收PS2信号以后我们便在遥控过程中发现了一个前面埋的坑，也就是困（1）里我们采用了掩码的方式来骗过失联装置，这直接导致了在现有的代码上（部分未给出的阻碍代码已）放在下面我们难以使用MOOD键来切换红绿灯模式，这为我们后续的全向与四向并用造成了不小的阻碍，并且一旦我们按下MOOD键，小车就会进入失联状态，跳过所有指令的执行。

  void AX_PS2_Init(void) {
  // 1. 等待手柄启动
  HAL_Delay(500);
  uint8_t i,retry,ret[9];
  // 2. 初始化通信引脚为空闲状态
  CS_H();
  CLK_H();
  CMD_H();
  HAL_Delay(10);
  //强制进入红灯模式
  const uint8_t cmd [9] = {0x01, 0x43, 0x00, 0x01, 0x00, 0x00, 0x00, 0x00, 0x00};

	for (retry = 0; retry < 5; retry++)     /* 最多重试 5 次 */
	{
		CS_L();
		for (i = 0; i < 9; i++) {
			ret[i] = PS2_ReadWriteData(cmd[i]);   /* ★ 这次接住返回值 */
		}
		CS_H();

		if ((ret[1] & 0x7F) == 0x73) break;  /* 成功进入模拟模式，退出重试 */
		HAL_Delay(100);

		// 4. 再次拉高空闲状态，准备进入主循环
		CLK_H();
		CMD_H();
		HAL_Delay(100);
	}
